პროექტის მიზანი
ფინალური პროექტის მიზანია, სტუდენტმა პრაქტიკაში გამოიყენოს კურსის განმავლობაში მიღებული ცოდნა და დამოუკიდებლად შექმნას დასრულებული, ვიზუალურად გამართული და სხვადასხვა მოწყობილობაზე ადაპტირებული ვებსაიტი.
